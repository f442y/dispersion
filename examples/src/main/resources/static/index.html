⚡ Dispersion Control Plane Spring Boot 4.1

Embedded control plane operational host running on Java 25 virtual threads with localized Spring Boot dependencies.

👁 Live REST Endpoints

  • • GET /api/v1/machines — List registered state machine topologies
  • • GET /api/v1/machines/OrderWorkflow — Inspect Order Saga workflow topology
  • • GET /api/v1/executions?status=SUSPENDED — Query suspended saga executions
  • • GET /api/v1/events/stream — Real-time Server-Sent Events (SSE) telemetry stream

📡 Signal Resumption Example (curl)

Resume pre-seeded suspended order ORDER-DEMO-99 via signal delivery:

curl -X POST "http://localhost:8080/api/v1/executions/signal" \
  -H "Content-Type: application/json" \
  -d '{"machineName":"OrderWorkflow","correlationKey":"ORDER-DEMO-99","signalName":"PaymentSignal","payload":{"correlationKey":"ORDER-DEMO-99","paymentMethod":"APPLE_PAY","amountCents":9995}}'
